# Veltrix — E-commerce demonstrativo

Site multipáginas desenvolvido como atividade escolar usando **HTML5, CSS3 e JavaScript puro**.

## Executar

Abra o link do github pages.

## Páginas

Home, catálogo, detalhes dinâmicos (`produto.html?id=...`), carrinho, checkout, confirmação, favoritos, login, cadastro, perfil e pedidos.

## Funcionalidades

- Pesquisa, categorias e ordenação por preço/avaliação.
- Adicionar ao carrinho, alterar quantidades, remover e recalcular totais.
- Favoritos com coração preenchido e persistência após atualização.
- Checkout com formulário, PIX, débito e crédito com parcelas (tudo simulado).
- Login e cadastro demonstrativos, sem backend nem autenticação verdadeira. **Não inserir senhas reais.**
- Tema claro/escuro e menu mobile.
- Armazenamento no navegador via `localStorage` (`sessionStorage` para filtros temporários).
- Catálogo variado: mouse, teclado, headset, monitor, SSD, webcam e mousepad.

## Observações

Os produtos, avaliações, características técnicas e valores são fictícios, destinados à demonstração. Nenhuma compra real, cobrança ou entrega acontece. As imagens de produtos vieram do material do projeto e de ilustrações geradas para uso neste trabalho.

## Arquivos principais

`style.css`: layout, responsividade e temas.

`script.js`: catálogo, renderização, carrinho, favoritos, formulários e histórico.

`img/`: imagens de produtos.
